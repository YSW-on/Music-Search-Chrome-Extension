## 개요

현재 활성화된 탭에서 재생 중인 음악을 감지하여 앨범 커버, 제목, 아티스트를 표시하는 크롬 확장 프로그램입니다.
음악 인식에는 AudD API가 사용됩니다.

## 사용 방법

1. [AudD 대시보드](https://dashboard.audd.io/)에 접속하여 계정에 로그인합니다.
2. 가려져 있는 `Your api_token:` 값을 표시하여 복사합니다.

**주의: 개인 AudD API 토큰은 비공개로 유지하고, 다른 사람과 절대 공유하지 마세요.**

3. 복사한 API 토큰을 `popup.js`의 다음 줄에 붙여넣습니다.
```javascript
const AUDD_API_TOKEN = "";
```
4. Chrome에서 `chrome://extensions/`를 엽니다.
5. 개발자 모드를 활성화합니다.
6. "압축해제된 확장 프로그램 로드"를 클릭하고 프로젝트 폴더를 선택합니다.

## 작동 방식

1. Search 버튼을 클릭하면 확장 프로그램이 현재 활성화된 탭의 ID를 가져옵니다.
2. 탭 ID를 이용해 해당 탭의 오디오를 캡처하는 데 사용할 수 있는 `streamId`를 얻습니다.
3. `streamId`를 이용해 현재 탭의 오디오 스트림을 가져옵니다.
4. 캡처한 오디오가 계속 들리도록, 캡처한 스트림으로 Web Audio API 오디오 소스를 만들어 오디오 출력에 연결합니다.
5. `MediaRecorder` API를 이용해 오디오 스트림을 6초 동안 녹음하고, 녹음된 데이터를 `Blob`으로 변환합니다.
6. `Blob`와 API 토큰을 `POST` 요청으로 AudD API에 전송합니다.
7. AudD가 곡을 성공적으로 식별하면, 응답에서 제목, 아티스트, `song_link` 등의 정보를 추출합니다.
8. AudD가 반환한 `song_link`가 가리키는 웹페이지에서 앨범 이미지를 가져옵니다.
9. 앨범 이미지, 제목, 아티스트를 확장 프로그램 팝업에 표시합니다.

## 주의 사항

- 인식 결과와 앨범 정보는 AudD API에서 제공되며 항상 정확하지는 않을 수 있습니다.
- API 요청 한도에 도달하면 음악 인식을 사용할 수 없습니다.
- 커버 버전이거나 배경 소음이 심한 경우처럼 오디오가 원곡과 크게 다르면 인식에 실패할 수 있습니다.
- AudD가 비슷한 멜로디나 오디오 구간을 가진 다른 곡을 반환할 수 있습니다.
- 인식에 성공하더라도, 반환된 결과가 원래 발매된 앨범이 아닌 컴필레이션 앨범 등 다른 앨범을 가리킬 수 있습니다.
